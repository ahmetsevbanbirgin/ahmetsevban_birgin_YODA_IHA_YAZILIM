Liste
	Köşeli parantez kullanılarak gösterilir. Birden fazla nesneyi kendi içinde tutmayı sağlar.
	List = [ “orange”, “yellow”, ”purple”, “blue”]
	Append ve insert komutu listeye eleman eklemek için kllanılır.
	List.append(“pink”) komutu girildiğinde, List = [ “orange”, “yellow”, ”purple”, “blue”, “pink”] şeklinde sonuç çıkar.
	List.insert(0,”red”) kodu yazıldığında sonuç List = [ “red”“orange”, “yellow”, ”purple”, “blue”] olur.
	Remove, pop ve del komutkarı listeden eleman silmek için kullanılır.
	List.remove(“orange”) girilirse sonuç List = [ “yellow”, ”purple”, “blue”] olur.
	List.pop() girilirse sonuç List = [ “orange”, “yellow”, ”purple”] olur.
	Del list[1] girilirse sonuç List = [ “orange”, ”purple”, “blue”] olur. 
	List[0] = “brown” girilirse List = [ “brown”, “yellow”, ”purple”, “blue”] olur.
	Len komutu eleman sayısını verir.
	List.reverse() komutu listeyi tersine çevirir yani list = [“blue”, “purple”, “yellow”, “orange”]
	Sort ve sorted komutları listeyi sıralar. Ancak sorted sunucunda liste aynı kalır.

Döngüler
1)	For Döngüsü
Liste, aralık gibi şeyler üzerinde çalışma yapacakken kullanılır.
Örnek: 
colours = ["red", "yellow", "blue", "brown"]
for colour in colours:
    print(colour)

2)	While Döngüsü
Belli komutları gerçekleştirmek için koşul doğru olduğunda çalışır.
Örnek:
i = 0
number = int(input("Enter a number:"))
while i <= number:
    print(i)
    i += 1

import random

number = random.randint(1, 100)
max_attempts = 10
attempts = 1

print("Can you guess the number which I have in my mind between 1 to 100:")
print(f"You have {max_attempts} attempts to estimate the number.")

while attempts <= max_attempts:
    try:
        guess = int(input(f"Attempt {attempts}, Enter your guess: "))
    except ValueError:
        print("Please enter an integer value!")
        continue  
    if guess == number:
        print(f"You guessed it right! The number is {number}. You took {attempts} attempts.")
        break
    elif guess < number:
        print("Your guess is low.")
    else:
        print("Your guess is high.")

  if attempts == max_attempts:
        print(f"You did not guess the number in {max_attempts} attempts. The number was {number}.")
        break

  attempts += 1

class Account:
    def __init__(self, owner, account_id, balance=0):
        self.owner = owner
        self.account_number = account_id
        self.balance = balance

  def deposit(self, amount):
       
  if amount > 0:
            self.balance += amount
            print(f"{amount}  deposited successfully.")
    else:
            print("Deposit amount have to be positive.")

  def withdraw(self, amount):
        
  if amount > self.balance:
            print("Insufficient balance.")
    elif amount <= 0:
            print("Withdrawal amount have to be positive.")
        else:
            self.balance -= amount
            print(f"{amount}  withdrawn successfully.")

  def show_balance(self):
        print(f"Current balance: {self.balance} TL")

  def show_info(self):
        print(f"Account Owner: {self.owner}")

        print(f"Balance: {self.balance} ")
