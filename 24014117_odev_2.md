# Github Temel Kavramlar ve Nasıl Kullanıldıkları
Git, bir proje yaparken kullanılan ana yerdir. Eğer birçok kişi bir projede çalışacaksa git, kullanıcıların kolay ve rahat bir şekilde senkronize olmasını sağlar ve bu nedenle çoğu yazılımcı kullanır.
Github, kullanıcıların projelerini buraya yükleyip diğer kullanıcılarla paylaşabildiği bir platformdur.
Config, gitteki kullanıcıların kendi iletişim bilgilerini gitte yazarken kullandıkları bir şeydir. Kullanım şekli şu şekildedir:    git config --global user.name "Your Name"
mkdir  gitte yeni bir dizin oluşturmak için kullanılır.
cd oluşturulan dizini seçmek için kullanılır. mkdir myproject	cd myproject
init gitte repository başlatmak için kullanılan bir komuttur. git init
Repository projedeki her şeyi depolayan, not eden bir klasördür.
Repository github kullanılarak oluşturulur.
status komutu ile dosyalardaki değişiklikler kontrol edilir.
Ls komutu klasördeki hangi dosyaların izlendiğini söyler.
add komutu dosya eklemek için kullanılır.
restore komutu eğer dosya yanlış yere konumlandırılmışsa onun yerini düzenlemek için kullanılır.
reset komutu o dosyaya kadar olan tüm dosyaları siler.
Commit dosyadaki değişiklikleri kaydeden bir şeydir. “git commit -m “ şeklinde yazılır.
Branch yeni şeyler eklemek için kullanılır, güvenilirdir.
Merge brancdeki değişiklikleri başka branch ile birleştirir.
Log repository deki tüm değişiklikleri görmek için kullanılır.
Push komutu ile yazdığın programı githubda paylaşmış olursun. Git push origin
Pull githubdaki içerikleri buraya alabilmeyi sağlar.  Git pull origin
Checkout branchlar arasında geçiş yapmayı sağlar.
Checkout -b yeni bir branch oluşturur ve ona geçiş yapar.
