Import cv2 : Cv2 kütüphanesini pythona ekler.
Cv2.imread() : Girdiğin dosyayı okur ve RAM’a atar.
Cv2.imwrite() : Girilen dosyayı harddiske kaydeder.
Cv2.waitKey( x ) : x  milisaniyede okunan kare sayısını belirler.
Cv2.destroyAllWindows() : Açılan pencereleri kapatır
Cv2.resize: Girilen dosyayı yeniden boyutlandırıyor.
Cv2.VideoCapture( ): Videoyu açar eğer içindeki sayı “0” ise webcami açar.
.read( ) : Videodaki her kareyi okur. İki adet parametre alır birisi ile okuma işleminde hata var mı diye sorulur diğeri ile de okunan kare girilir.
Cv2.cvtColor() : Dosyanın rengini değiştirmeye yarar.
